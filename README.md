# 雾林小屋 · 程序化 3D 场景（Three.js）

一个**全程序化生成**的实时 3D 森林小屋场景：没有外部模型、没有贴图文件、没有任何素材下载，
所有几何体、纹理（Canvas 现画）、雾、灯光、粒子、后处理都是代码算出来的。

> 参考：抖音上「DeepSeek 一轮对话花 8 毛钱做出的 3D 森林小屋」那条视频的效果。
> 本项目是用**同样的思路**（对话生成一个 Three.js 网页）在本会话里一次性搭出来的复刻 demo。

## 打开方式

直接**双击 `index.html`** 即可（本地 classic script，不需要起服务器、不需要联网）。
建议用 Chrome / Edge 打开；首次加载会即时生成贴图与场景，约 1~3 秒。

## 操作

| 控制 | 说明 |
| --- | --- |
| 自动 | 电影感自动运镜（默认），缓慢推近小屋 |
| 漫游 | 自由视角：**按住鼠标拖动**环视，**WASD** 走动，**Shift** 加速，滚轮推拉 |
| 雾重 | 点击循环「淡 / 中 / 浓」 |
| 机位 | 点击切换 4 个预设机位（远景 / 林间 / 门前 / 斜侧） |
| 截图 | 把当前画面导出 PNG（浏览器直接下载） |
| 全屏 | 全屏观看 |

URL 参数（方便录屏/截固定机位）：

```
index.html?cam=0            # 0~3 固定机位（= 远景/林间/门前/斜侧）
index.html?cam=auto         # 自动运镜（默认）
index.html?ui=0             # 隐藏 UI（干净画面，录屏用）
index.html?ss=1.5           # 超采样倍率 1~2（画质/性能取舍）
index.html?fog=0.7          # 雾浓度 0~1
```

## 效果构成

- **场景**：木屋（墙体/屋檐/屋脊/老虎窗/烟囱/门廊/栏杆/台阶/花环/百叶窗/窗台花箱）、
  石板路（曲线条带 + 程序化铺装贴图）、树林（树干/枝干/树冠面片）、远景树线、篱笆、鸟屋、蘑菇、萤火虫
- **氛围**：指数雾、暖色窗光 + 点光源、门廊吊灯、炊烟粒子、体积光柱、地面薄雾、尘埃、萤火虫闪烁
- **后处理**（自己写的 WebGL 管线，不依赖 EffectComposer）：
  亮部提取 → 两级高斯模糊 Bloom → 伪景深（下沿/顶部/左右虚化）→ ACES 色调映射 → 冷暖分级 → 暗角 → 胶片颗粒
- **性能**：普通独显/核显可 60fps；`?ss=2` 或 4K 屏会明显吃性能

## 文件结构

```
index.html            入口 + UI/样式
src/textures.js       全部程序化贴图（木板、瓦片、石板、树皮、树叶、草、窗光、雾、光柱……）
src/main.js           场景搭建、相机控制、粒子、后处理管线
vendor/three.min.js   three.js r149（本地内置，保证双击可开）
tools/                开发期用的无头 Chrome 截图/CDP 调试脚本（不是运行必需）
preview/              渲染出的预览图
```

> 说明：目录里的 `.chrome-*` 是开发期无头 Chrome 的临时配置目录（约 2MB，当前被残留进程占用，
> 重启电脑或关闭残留 chrome 后可随手删掉），不影响场景运行。

## 和原视频的差距（老实说）

1. 原视频画面更接近 UE5 + 专业美术资产；本 demo 是纯代码程序化建模，**风格/氛围接近，资产精度达不到**。
2. 树叶是程序化贴图面片，近看是「片状」的；原视频更接近真实植被。
3. 没有真实深度图，景深是屏幕空间伪造的（目前效果够用，但不是物理正确）。
4. 想更接近原视频：换真实 glb 模型/贴图，或用 Blender 手搭模型再烘渲染（成本高一个量级）。

## 可扩展

- 改 `src/main.js` 中 `PRESETS` 换机位；改 `applyFog` 调雾曲线；改 composite shader 调色调
- 想发抖音：可加自动相机轨迹 + 逐帧截图/录屏，再 ffmpeg 合成 mp4（本会话已验证环境里有 ffmpeg）
- 换品牌名/Logo：`index.html` 里 `MISTY FOREST CABIN` 改成自己的即可
